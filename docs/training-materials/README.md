# JYC Equipment Training Materials & Reference Scripts

This directory houses the foundational training documentation, industrial industry scripts, gatekeeper handling playbooks, and equipment catalogs that power the **JYC Equipment AI Sales Trainer** simulation and scoring engine.

---

| File | Description | Target Industry / Sector | Primary Focus |

| **`Plastic Script.pdf`** | Cold outreach script & objection handling for polymer manufacturers and blow/injection molders. | Plastics & Polymers | Injection molders (Toshiba, Nissei, Engel), extruders, chillers. Strict Matrix zero trade-in rule. |

| **`brochure de metal.pdf`** | Industrial equipment inventory and metalworking machinery catalog. | Metalworking & Fabrication | CNC machines, stamping presses, shears, metal fabrication lines. |
